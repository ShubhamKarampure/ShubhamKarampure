### Real-time Distributed Scribble Game
* Developed distributed multiplayer drawing/guessing game using Node.js, Socket.IO, and MongoDB.
* Engineered real-time synchronized drawing/chat; scaled Socket.IO horizontally with a Redis Pub/Sub adapter.
* Implemented Bully Algorithm for leader election (fault tolerance) & Vector Clocks for causal event-order consistency.
* Utilized RabbitMQ for asynchronous game analytics processing & a gRPC microservice for decoupled word generation.

### Devanagari Glyph Generation via Denoising Diffusion Models
* Curated 57k+ Devanagari graphemes; trained UNet-based DDPMs (PyTorch, Hugging Face Diffusers) on varied data subsets.
* Quantitatively assessed generation quality (SSIM, FID), showing 25% data achieves 95% of peak fidelity.
* Benchmarked inference schedulers (DDIM, DPMSolver, Euler variants) to optimize output fidelity vs. sampling speed.
